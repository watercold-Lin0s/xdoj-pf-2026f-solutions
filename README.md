# XDOJ 程序设计基础（2026 秋）题解

XDOJ 在线评测平台《程序设计基础》课程的练习代码，共 22 题。从 `Hello, World!` 起步，逐步做到温度换算、四则运算、质数判断、欧几里得算法，再到复利、个税分段计算、迭代法求平方根和亲和数判断。

## 说明

- 语言：C。文件后缀用的是 `.cpp`，代码是 C 风格，用 `g++` 或 `gcc` 都能编译。
- 一题一文件，**文件名即 XDOJ 题号**。
- 每份代码顶部记录了题目名称、作者和完成日期。
- 输入都做了校验，并处理了除零、非法输入、数值越界等边界情况。

```bash

```

```bash

```
